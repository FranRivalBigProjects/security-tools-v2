CSRF guide for DevOps teams

What is CSRF and why do DevOps teams care?
CSRF (Cross-Site Request Forgery) tricks a logged-in user's browser into making unauthorized requests to your application. An attacker's malicious page sends a form POST to your API — the browser automatically includes the user's session cookie, so the server processes it as legitimate. DevOps teams need to ensure CSRF protection is present in every deployment — framework middleware is often accidentally disabled, excluded from API routes, or misconfigured when migrating between frameworks.

SameSite cookies — the modern CSRF defense
Modern browsers support the SameSite cookie attribute which prevents cookies from being sent on cross-site requests. SameSite=Strict — cookie never sent on cross-site requests (safest, but breaks OAuth flows). SameSite=Lax (browser default since 2020) — sent on top-level navigation GET requests, blocked on cross-site POST. SameSite=None; Secure — required for cross-site requests (e.g., third-party APIs, embeds). Set SameSite in your session cookie configuration — for most apps, Lax provides CSRF protection without breaking OAuth.

REST APIs and CSRF — when you can skip CSRF tokens
Stateless REST APIs using JWT Bearer tokens in Authorization headers are not vulnerable to CSRF — browsers don't automatically send custom headers on cross-site requests. Skip CSRF middleware for: APIs authenticated with Authorization: Bearer TOKEN, APIs authenticated with API keys in headers. Keep CSRF protection for: APIs that accept session cookies for authentication, any endpoint that performs state changes and is accessed from a browser session.

FAQ — CSRF tools for DevOps
Scanning tools: OWASP ZAP (free, active CSRF scanning, CI/CD integration), Burp Suite Pro (CSRF PoC generator), Nuclei (fast, template-based, great for CI). Framework middleware: @fastify/csrf-protection (Node.js), Django CsrfViewMiddleware (built-in), Laravel VerifyCsrfToken (built-in), Spring Security CsrfFilter (built-in). Code review: Semgrep with OWASP Top 10 ruleset catches missing CSRF middleware at PR time. This tool: quick HTML/header paste-and-check for immediate feedback.
